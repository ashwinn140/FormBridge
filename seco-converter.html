Rule types — Direct: copy the source field as-is. Constant: always use Default. Date: reformat the source value using the pattern in Rule/formula (e.g. DD.MM.YYYY). Lookup: convert the source field using a list such as IN=YES, *=NO. Template: build text from a pattern with source columns in curly braces, e.g. {Item Name} — all braces must reference the sheet named in Source sheet. SQC Qty and SQC Unit are not set in the Mapping table above — they're driven entirely by the HS Code rules table, since they vary by HS code rather than being fixed.
